# Third-party sources

- **COCO:** [dataset](https://cocodataset.org/), [terms](https://cocodataset.org/#termsofuse), [official annotation archive](https://s3.amazonaws.com/images.cocodataset.org/annotations/annotations_trainval2017.zip). The committed manifest is a small excerpt of bounding-box annotations with source IDs, links, and image-license metadata. Source images are downloaded at runtime and are not relicensed under this project's MIT code license. Respect the original image licenses, including attribution and any noncommercial restrictions. The generated comparison images retain the underlying image terms.
- **Torchvision:** [SSDLite model documentation](https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.detection.ssdlite320_mobilenet_v3_large.html). We use fixed COCO_V1 pretrained weights and the official inference implementation. No detector accuracy claim from its original benchmark is substituted for our own measured results.
- **AI2-THOR:** [repository](https://github.com/allenai/ai2thor), [Colab examples](https://github.com/allenai/ai2thor-colab), [state API](https://ai2thor.allenai.org/ithor/documentation/environment-state/). Simulator code and assets retain their original terms. The optional collector uses visible instance-mask bounding boxes.
- **ADMM:** Boyd et al., *Distributed Optimization and Statistical Learning via the Alternating Direction Method of Multipliers*, 2011. [Paper and examples](https://web.stanford.edu/~boyd/papers/admm_distr_stats.html).
- **Numerical and plotting libraries:** NumPy, SciPy, scikit-image, Pillow, and Matplotlib retain their own licenses.
